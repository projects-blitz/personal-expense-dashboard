# 💰 Dashboard de Gastos Personales

Aplicación web que permite visualizar, analizar y filtrar gastos personales mediante tablas dinámicas y gráficos interactivos.

---

## 🚀 Descripción

Este proyecto consiste en un **dashboard interactivo** desarrollado con JavaScript puro que permite al usuario:

- Visualizar sus gastos en una tabla
- Calcular el total gastado
- Filtrar por mes y categoría
- Analizar sus hábitos de consumo
- Ver la distribución de gastos mediante un gráfico de torta

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Chart.js (para visualización de datos)

---

## 📊 Funcionalidades principales

✅ Visualización de gastos en tabla  
✅ Cálculo automático del total gastado  
✅ Conteo de número de gastos  
✅ Filtrado por mes  
✅ Filtrado por categoría  
✅ Gráfico de torta dinámico por categoría  
✅ Actualización automática del gráfico al aplicar filtros  
✅ Formato profesional de moneda
